PC Components Explained

Welcome to the PC Components Section of Apsy's Tech! Learn what each computer component does, how it affects performance, and what you should understand before building your own gaming PC.

Explore PC Components

A computer is made of several components that work together. Each part has a different job, and choosing compatible parts is essential when building a PC.

Processing

1. CPU — Processor

The Central Processing Unit (CPU) executes instructions and handles calculations, game logic, and many system tasks. It is often called the brain of a computer.

  • Important features: cores, threads, clock speed.
  • Examples: Intel Core and AMD Ryzen.
  • Affects gaming, multitasking, and productivity.
Graphics

2. GPU — Graphics Card

The Graphics Processing Unit (GPU) processes graphics and helps render game worlds, visual effects, and high-resolution images.

  • Important features: performance, VRAM, power use.
  • Examples: NVIDIA GeForce RTX and AMD Radeon RX.
  • Especially important for demanding games and 3D work.
Mainboard

3. Motherboard

The motherboard connects the CPU, RAM, storage, graphics card, and other devices so they can communicate.

  • Check the CPU socket and chipset.
  • Check RAM type and supported capacity.
  • Check expansion slots and storage connections.
Memory

4. RAM

Random Access Memory (RAM) temporarily stores data that the computer is actively using. It is much faster to access than ordinary long-term storage.

  • Capacity is measured in GB.
  • Examples: DDR4 and DDR5.
  • More memory can help with multitasking and demanding applications.
Storage

5. SSD and HDD

Storage keeps your operating system, applications, games, and files even when the computer is turned off.

  • SSD: fast storage with no moving parts.
  • HDD: mechanical storage, often useful for large files.
  • NVMe SSDs use a high-speed interface over PCIe.
Power

6. PSU — Power Supply

The Power Supply Unit converts electricity from the wall into the power required by your PC components.

  • Check total system power requirements.
  • Check connector requirements.
  • Choose a reliable unit with suitable capacity and protections.
Temperature

7. Cooling System

Cooling removes heat from components and helps them operate within their supported temperature limits.

  • Air cooling uses heatsinks and fans.
  • Liquid cooling moves heat through a liquid loop.
  • Case airflow helps move hot air out of the PC.
Structure

8. PC Case

The case houses and protects your components. It also affects airflow, available space, and how easy the system is to assemble.

  • Common sizes include ATX, Micro-ATX, and Mini-ITX cases.
  • Check motherboard and graphics card clearance.
  • Check cooler, radiator, and PSU space.
Remember: A powerful GPU alone does not guarantee a balanced gaming PC. CPU performance, memory, cooling, storage, and component compatibility also matter.

PC Compatibility Guide

Before buying components, check that the parts support one another. These are some of the important checks.

Components What to Check
CPU + Motherboard Socket, chipset support, and BIOS compatibility.
Motherboard + RAM Supported DDR generation, capacity, and memory configuration.
GPU + Case Graphics card length, thickness, and clearance.
CPU + Cooler Socket mounting support and cooling capacity.
PSU + Components Suitable wattage, quality, and required power connectors.
Motherboard + Case Motherboard form factor and case support.
Storage + Motherboard Available M.2 slots, supported drive types, and SATA connections.
Compatibility details vary by model. Always check the manufacturers' specifications before purchasing parts.
